# GAMELAB - Muestra Académica

## Cómo usar

1. Abre la carpeta del proyecto.
2. Abre `index.html` con Visual Studio Code / Visual Studio.
3. Coloca tus imágenes dentro de la carpeta `img`.
4. Usa los nombres indicados abajo o cambia las rutas en `index.html`.

## Imágenes que debes reemplazar

- `img/proyecto-destacado.jpg` → imagen grande del proyecto principal.
- `img/proyecto-1.jpg` → proyecto 1.
- `img/proyecto-2.jpg` → proyecto 2.
- `img/proyecto-3.jpg` → proyecto 3.
- `img/proyecto-4.jpg` → proyecto 4.
- `img/proyecto-5.jpg` → proyecto 5.
- `img/noticia-1.jpg` → imagen de noticia 1.
- `img/noticia-2.jpg` → imagen de noticia 2.

También puedes cambiar los nombres, textos y categorías directamente en `index.html`.

## Para tu compañero

El frontend ya deja preparado:

- botón de Login
- perfil
- proyectos
- navegación
- área para carrito si desean agregarlo
- estructura de tarjetas
- diseño responsive

El botón de Login actualmente muestra un aviso. Tu compañero puede sustituirlo por la navegación hacia su sistema de login o por la conexión con su backend.

## Importante

La página usa Font Awesome desde CDN para los iconos. Si la computadora donde presentarán el proyecto no tiene Internet, conviene descargar Font Awesome y alojarlo localmente.
